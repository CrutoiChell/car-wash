# Car Wash

Сайт автомойки на Next.js и TypeScript с формой заявки и передачей контактных данных в Telegram через серверный API-маршрут.

[Демо](https://myautowash.vercel.app/)

## Возможности

- страницы услуг и заявки;
- передача имени, телефона, модели автомобиля и примечания в Telegram;
- серверное хранение токена бота в переменных окружения;
- обработка ответа и ошибок Telegram API;
- интерфейс на React и SCSS.

## Стек

Next.js 15.3.4 (App Router), React 19, TypeScript, Redux Toolkit, React Redux, Sass и Telegram Bot API.

## Как устроена отправка

Форма передаёт данные в `POST /api/send-to-telegram`. Серверный обработчик формирует сообщение и вызывает Telegram Bot API. Это передача заявки владельцу, а не подтверждение свободного времени или бронирование слота.

## Локальный запуск

```bash
npm install
```

Создайте `.env.local` в корне проекта:

```dotenv
TELEGRAM_BOT_TOKEN=your_bot_token
TELEGRAM_CHAT_ID=your_numeric_chat_id
```

Используйте отдельного тестового бота и чат для проверки. Не добавляйте реальные ключи в Git.

```bash
npm run dev
```

Откройте http://localhost:3000.

Для сборки и запуска production-версии:

```bash
npm run build
npm run start
```

## Ограничения

Для отправки заявок нужны настроенные Telegram-переменные. Перед использованием в production следует дополнительно проверить серверную валидацию входных данных и защиту формы от спама. Успешная сборка и работа внешней интеграции в рамках проверки документации не подтверждены.
